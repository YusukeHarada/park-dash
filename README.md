## 🎮 Animal Escape! — スマホゲーム

Car Jam / Sheep Dash 風の動物脱出パズルゲーム。
6×6グリッドに配置された動物たちをスライドさせて全員グリッド外へ脱出させるとクリア。

### ゲームシステム

| 項目 | 内容 |
|------|------|
| **移動方式** | **オートスライド** — タップ選択 → 矢印タップ or スワイプで動物がブロック or グリッド端まで一気にスライド |
| **グリッド** | 6×6、四辺すべてに出口あり |
| **評価** | ⭐⭐⭐ ≤ par、⭐⭐ ≤ par×1.5、⭐ クリア |
| **Undo** | 3回/ステージ（残数アイコン表示） |
| **レベル** | 10ステージ（チュートリアル → マスター） |
| **キャラクター** | 🐑🐥🐷🐰🐮🦆🐱🐶 8種の動物 |

### 遊び方

```bash
cd game
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

ビルドツール不要。`game/index.html` をブラウザで直接開いても動作します。

### ファイル構成

```
game/
├── index.html              # エントリーポイント (Phaser 3.60 CDN)
└── src/
    ├── main.js             # Phaser 設定
    ├── data/levels.js      # 10ステージのレベルデータ (par 値付き)
    ├── objects/Animal.js   # 動物ピースクラス (方向矢印・オートスライド)
    └── scenes/
        ├── MenuScene.js    # レベル選択 (スター・ロック表示)
        └── GameScene.js    # ゲーム本体 (衝突判定・スター評価・Undo)
```
